# LoadShift

## Run locally

```bash
npm install
npm run dev
```

The app needs these variables from `.env`:

```text
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=....
OPEN_ELECTRICITY_API_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...
AWS_CONTROL_REGION=...
AWS_REGION=...
AWS_LOADSHIFT_PRINCIPAL_ARN=...
AWS_LOADSHIFT_ACCOUNT_ID=...
AWS_SECRET_ACCESS_KEY=...
AWS_ACCESS_KEY_ID=...
```
